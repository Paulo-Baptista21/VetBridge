
## Requisitos Funcionais

|Código|Requisito|
|---|---|
|RF01|O sistema deve permitir a pesquisa de um termo por vez.|
|RF02|O sistema deve apresentar os sinais clínicos, princípios ativos e nomes comerciais relacionados ao termo pesquisado.|
|RF03|O sistema deve exibir as apresentações comerciais vinculadas ao nome comercial selecionado e as espécies para as quais existe uso farmacológico cadastrado.|
|RF04|O sistema deve exibir as informações farmacológicas correspondentes à apresentação comercial e à espécie selecionadas.|
|RF05|O sistema deve calcular a dose em miligramas a partir do peso do animal em quilogramas e da dose em mg/kg cadastrada no respectivo uso farmacológico.|
|RF06|O sistema deve permitir o retorno ao menu inicial.|
## Requisitos não funcionais

| **Código** | **Requisito**                                                                                     |
| ---------- | ------------------------------------------------------------------------------------------------- |
| RNF01      | O sistema deve responder às consultas em até 2 segundos.                                          |
| RNF02      | O sistema deve funcionar em Windows e Linux.                                                      |
| RNF03      | O sistema deve possuir interface intuitiva.                                                       |
| RNF04      | O sistema deve utilizar apenas informações provenientes de bulas oficiais.                        |
| RNF05      | O sistema deve permitir futuras atualizações da base farmacológica sem alteração do código-fonte. |
